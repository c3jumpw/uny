# Partner tool logos

Logo files for the tools featured on unywebs.com, used in the guide
explainer videos. Each is served from
`https://unywebs.com/media/logos/tools/<file>`.

| Tool | Files | Source |
| --- | --- | --- |
| Zapier | `zapier.png/.svg` (wordmark), `zapier-icon.png/.svg` | SVG Logos by Gil Barbara, CC0 |
| Notion | `notion.png/.svg`, `notion-icon.png/.svg` | SVG Logos by Gil Barbara, CC0 |
| ClickUp | `clickup.png/.svg`, `clickup-icon.png/.svg` | SVG Logos by Gil Barbara, CC0 |
| Zoho (Mail) | `zoho.png/.svg` | SVG Logos by Gil Barbara, CC0 |
| Quo | add `quo.png` | Quo's official brand kit (see quo.com/press) |
| Systeme.io | add `systeme.png` | brandfetch.com/systeme.io |
| Manychat | add `manychat.png` | brandfetch.com/manychat.com |
| Synthesia | add `synthesia.png` | Wikimedia Commons: File:Synthesia_Logo_2024.png |

PNGs are 1024 px wide with a transparent background. The CC0 licence
covers the files; each name and logo is still its owner's trademark, so
use them as-is (no recolouring, stretching or effects) to refer to the
product.

UnyBase and Unywebs logos live one folder up, in `media/logos/`.
